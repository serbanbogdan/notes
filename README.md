Te am rugat sa faci o regula pentru valorile ce depaste 0 sau 100 pe SP normalizat
"Corecție (opțională, implicit activă): valorile peste 100 sau sub 0 se apropie de limită — excesul se împarte la k (implicit 10): SPN > 100 → 100 + (SPN − 100)/k; SPN < 0 → SPN/k. Ex.: 150 → 105, −80 → −8, −100 → −10; între 0 și 100 nu se schimbă nimic, iar ordinea valorilor se păstrează."
din pcata regula aceasta imi aplatizeaza varfurile ce depaste acete valor pot isa imi fai o alta regula ca sa corectez cuma cea ce depaste 0 sau 100 si sa fie ceva logaritmic sa raman toit cepa spikurie dar sa nu depasta mutla limitele. Si mai vreau opriuen sa alega sau nu corectia respectiva
